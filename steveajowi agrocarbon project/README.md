# Ajowi AgroCarbon Token MRV

A React + Vite prototype for the Ajowi AgroCarbon Token monitoring, reporting, and verification workflow.

## What it includes
- Farm registry cards with sample project data
- MRV measurement summaries and evidence tracking
- Verification workflow status and checklist
- Token issuance tracking for verified carbon volume
- Project objectives, verification inputs, farm gadgets, and compliance references
- Responsive dashboard styling tuned for a carbon MRV product demo

## Scripts
- `npm run dev` - start the development server
- `npm run build` - type-check and build for production
- `npm run preview` - preview the production build

## Notes
This workspace ships with mock data so the UI can be developed before backend, IoT, and blockchain integrations are ready.
The current build is intended as the front end for a carbon MRV system, not a final carbon-credit issuance implementation.
